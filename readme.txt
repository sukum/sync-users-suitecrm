Send selected WordPress users to SuiteCRM as contacts, leads, or accounts, automatically or when you choose.
== Frequently Asked Questions ==
= Supported SuiteCRM versions =
SuiteCRM 7.10 onwards. Including SuiteCRM 8.
= How is the data exchanged with SuiteCRM =
Using the v8 Rest Api instroduced in SuiteCRM 7.10.
= Does it support pulling data from SuiteCRM to Wordpress =
No. Currently only pushing of Wordpress users is supported.
